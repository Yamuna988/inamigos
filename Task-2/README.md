# Task 2 – AI-Powered Education: Social Impact

## Objective

The objective of this task was to understand how Artificial Intelligence can improve education and create a positive social impact.

## Work Done

* Researched the role of AI in education.
* Studied how AI can help students and teachers.
* Identified the benefits and challenges of AI in education.
* Presented the information using charts and visual elements.
* Created a PowerPoint presentation based on the research.

## Tools Used

* Microsoft PowerPoint
* AI tools for research and content preparation
* Charts and visualizations

## Key Learning

Through this task, I learned how AI can make education more accessible, personalized, and effective. I also understood some of the challenges that need to be considered while using AI in education.
